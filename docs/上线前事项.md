# 上线前事项

## 静态网页

`web/` 和 `shared/` 可以放在静态托管服务上，保留相邻的目录结构。浏览小事、筛选、随机挑选和收藏无需后台。收藏保存在访问者的浏览器中，不会自动同步到其他设备。

公开 GitHub 源码不会自动创建已上线的网站，也不会运行闲聊接口。当前仓库没有配置在线网页地址；托管服务的可用性与访问体验需要实际验证。

## 公开闲聊

`server/` 只监听 `127.0.0.1`，供本机开发和测试使用。它没有正式账号体系，不应直接暴露为公网社区后台。公开社区需要另外准备身份、审核、防滥用、备份、隐私说明与托管。

目前留言和回复采用人工审核，没有接入自动内容安全服务。预览与测试内容不能冒充真实用户分享。

## 费用和广告

当前代码没有接入广告或用户收费。静态网页可以选择免费托管；公开闲聊服务需要另行评估成本。

若今后加入广告，应少量、明确标注，不伪装成用户分享，不要求看广告才能浏览小事。

## 许可

代码与文字的许可尚未确定，目前先公开源码。第三方素材的权利需要分别核对。
