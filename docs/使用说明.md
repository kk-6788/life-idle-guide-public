# 使用说明

## 只想看看小事

需要已有的 Python 3。在仓库根目录运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8000/web/](http://127.0.0.1:8000/web/)。可以搜索、筛选、随机挑选和收藏；无需注册，收藏存在当前浏览器中。清理浏览器数据会同时清理收藏。

静态模式的「大家闲聊」会显示社区服务尚未开放。直接双击 HTML 可能无法读取内容文件，请使用上面的本机地址。

## 用转盘随便挑一件

点击转盘中间的「转一下」，或者筛选区的「转盘挑一个」。停止后会显示抽中的小事、格言和费用说明；点「看看这件小事」打开详情，也可以继续转。

转盘从当前搜索与筛选的完整结果里抽取，每轮最多显示八个候选。有多件可选时尽量不重复上一件；只剩一件时可以再次抽到它。修改筛选或离开浏览页会取消正在进行的转动，不会留下过期的结果。没有匹配时按钮不可用。

开启系统的“减少动态效果”后，转盘会直接显示抽取结果，不播放旋转动画。

## 在本机试试闲聊

Windows 可以双击仓库根目录的 `启动网页.cmd`。它会使用已有的 Python，也可复用已安装的 Hermes Python 环境，不会安装软件或改机器设置。

也可以手动运行：

```bash
python server/app.py
```

打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。服务只监听 `127.0.0.1`，默认数据库为 `work/community.sqlite3`，首次启动时自动创建。

如需更换端口或数据库：

```bash
python server/app.py --port 9000
python server/app.py --db path.db
```

留言与回复先进入待审核状态，不会立即对其他访问者展示。

## 审核留言和回复

在项目根目录运行：

```bash
# 查看待审核内容和举报
python server/moderate.py list

# 查看所有状态的内容和举报
python server/moderate.py list --all

# 批准一条留言，id 来自列表
python server/moderate.py approve --type post --id 1

# 隐藏一条回复
python server/moderate.py hide --type comment --id 2
```

如果启动服务时指定了数据库，审核时也使用同一路径，例如 `python server/moderate.py --db path.db list`。举报会被记录供管理员处理，不会自动封禁。

## 修改内容

编辑 `shared/content.json`，网页下次重新加载时会读取新内容。收录与费用规则见 [内容规则](../CONTENT_GUIDE.md)，提交方法见 [贡献指南](../CONTRIBUTING.md)。

## 放到线上

`web/` 和 `shared/` 可以使用静态托管，保留相邻目录结构后访问 `/web/`。这只能提供浏览、筛选、随机挑选和浏览器收藏，不会自动运行闲聊后台。

本机闲聊服务没有正式账号体系，不能直接作为公网社区服务。公开上线前看 [上线前事项](上线前事项.md)。
